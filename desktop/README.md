# ريڤو لسطح المكتب (ويندوز وماك)

تطبيق كمبيوتر خفيف يفتح النظام المستضاف نفسه (الحساب نفسه والبيانات نفسها) ويضيف ما لا يستطيعه المتصفح:

- **طباعة صامتة** على الطابعات المثبّتة على الكمبيوتر (تعريف ويندوز أو ماك) من دون نافذة طباعة: تُرسل الورقة بلغة الطابعات الحرارية (ESC/POS) عبر التعريف، وإن رفضها التعريف تُطبع كصفحة.
- **طابعات الشبكة**: الورقة تُرسل مباشرة إلى عنوان الطابعة على المنفذ 9100، ويعرض النظام إن كانت الطابعة تستجيب.
- **طابعات USB** بلا تعريف: قائمة اختيار للطابعة الموصولة.
- نافذة تتذكر حجمها ومكانها، صفحة واضحة إن لم يتوفر إنترنت في أول تشغيل، وتنبيه عند صدور نسخة جديدة من التطبيق.

الكمبيوتر الذي يعمل عليه التطبيق هو «وكيل الطباعة» للمطعم: الطلبات التي تُسجَّل من الهواتف والأجهزة الأخرى تُطبع منه تلقائيًا.

## كيف تُبنى النسخ

لا يُبنى التطبيق على جهازك، بل على خوادم GitHub مجانًا:

1. ارفع مجلد `desktop` إلى المستودع `hussain98898/revo` (الفرع main).
2. أنشئ الملف `.github/workflows/desktop.yml` في المستودع (Add file › Create new file، اكتب هذا المسار، والصق محتوى `desktop/github-workflow-desktop.yml`).
3. يبدأ البناء وحده. بعد نحو 15 دقيقة تظهر النسختان في صفحة Releases: `Revo-Setup.exe` لويندوز و`Revo.dmg` لماك.
4. أزرار التنزيل في الموقع تشير دائمًا إلى آخر إصدار: `https://github.com/hussain98898/revo/releases/latest`.

لإصدار نسخة جديدة: غيّر `version` في `desktop/package.json` (مثلًا 1.0.1) وارفع الملف، أو من تبويب Actions › Desktop apps › Run workflow واكتب رقم الإصدار.

## البناء على جهازك (اختياري)

يحتاج Node.js 22 أو أحدث:

```
cd desktop
npm ci
npm start            # تشغيل مباشر للتجربة
npm run dist:mac     # على ماك: release/Revo.dmg
npm run dist:win     # على ويندوز: release/Revo-Setup.exe
```

## التوقيع

النسخ غير موقّعة بشهادة من مايكروسوفت أو آبل، فيظهر تنبيه عند أول تشغيل فقط. عندما تتوفر شهادة توقيع تُضاف كأسرار في GitHub ويُفعَّل التوقيع في `package.json` (`mac.identity` و`win.certificateFile`).

## الملفات

- `main.js`: نافذة التطبيق، الأذونات، اختيار طابعة USB، قنوات الطباعة، القائمة، فحص التحديث.
- `preload.js`: الجسر `window.revoDesktop` الذي يراه النظام.
- `lib/printing.js`: الإرسال عبر الشبكة، الإرسال الخام عبر تعريف الطابعة (PowerShell على ويندوز، `lp` على ماك)، فحص الاتصال.
- `lib/state.js`: حفظ حالة النافذة.
- `offline.html`: الصفحة التي تظهر إن لم يُفتح التطبيق من قبل ولا يوجد إنترنت.
- `build/`: الأيقونات، وتوقيع ad-hoc لنسخة ماك بعد التغليف.
- `test/printing.test.js`: اختبار مكتبة الطباعة بطابعة شبكة وهمية (`npm test`).

عنوان النظام المستضاف مضبوط في `main.js` (`APP_URL`) ويمكن تغييره بمتغير البيئة `REVO_URL` عند التجربة.
